
# Linear Algebra Student Performance Analysis

## Project Overview

This project demonstrates the application of Linear Algebra concepts using a student performance dataset.  
The main objective is to analyze and transform data using vectors, matrices, decompositions, and dimensionality reduction techniques commonly used in Data Science, Artificial Intelligence, and Machine Learning.

The project includes both theoretical explanations and practical implementation in Python using Jupyter Notebook.

---

## Project Objectives

The project focuses on:

- Representing student scores using vectors and matrices
- Performing vector operations such as:
  - Norm-1 and Norm-2
  - Dot product
  - Cross product
  - Vector projection
- Performing matrix operations:
  - Matrix multiplication
  - Transpose
  - Determinant
  - Inverse
- Understanding eigenvalues and eigenvectors
- Applying LU Decomposition
- Applying Singular Value Decomposition (SVD)
- Performing dimensionality reduction using:
  - Principal Component Analysis (PCA)
  - Linear Discriminant Analysis (LDA)
